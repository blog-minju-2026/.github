# 한채

한 사람이 한 채의 집을 짓고, 그 안에 기록을 쌓고, 이웃의 집을 찾아가는 블로그 서비스.

블로그를 집 한 채로, 블로그들이 모인 곳을 마을로 본다. 글은 집 안의 방에 쌓이고, 같은 주제의 글은 마을의 골목에 모인다.

## 한채의 말

| 한채에서 | 흔히 부르는 이름 |
| --- | --- |
| 한채 | 블로그 |
| 마을 | 첫 화면. 모든 한채의 공개 기록이 모이는 곳 |
| 대문 · 현판 | 블로그 첫 화면 · 블로그 이름 |
| 마당 | 한 블로그의 글 목록 |
| 기록 | 글 |
| 방 · 마루 | 블로그 안의 카테고리 · 카테고리 없음 |
| 골목 | 마을 전체의 주제 (10개) |
| 이웃 | 구독 |
| 방명록 | 방명록 |

## 할 수 있는 것

- **한채 짓기** — 주소 · 현판 · 주인 소개를 정하면 대문이 생긴다
- **기록 쓰기** — 사진, 방, 골목, 태그, 공개 범위(공개 · 나만 보기)를 고른다
- **마을 둘러보기** — 골목별 기록, 새 기록, 이웃 소식, 지금 많이 읽는 기록, 북적이는 한채
- **찾기** — 마을 전체 또는 한 한채 안에서 기록과 한채를 찾는다
- **이웃과 어울리기** — 공감, 댓글, 방명록, 이웃 맺기
- **내 한채 꾸리기** — 한채 관리, 방 관리, 기록 관리, 내 정보

바뀐 내용은 사이트의 '릴리즈' 버튼(`/releases`)에서 볼 수 있다.
